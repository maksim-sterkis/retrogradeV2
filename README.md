# Retrograde

A precision spaceflight game about thrust, momentum, and careful landings. Guide your ship through challenging courses, avoid hazards, and reach the landing pad in one piece.

## Features

- 30 campaign levels and a flight tutorial.
- Practice and speedrun modes with personal best times.
- Replays and ghost racing.
- Local two-player split screen.
- Ship customization with unlockable patterns and symbols.
- A built-in level editor for creating your own courses.
- Progress saving and downloadable backups.
- Online leaderboards and optional accounts.

## Play

Download the HTML game file from this repository and open it in a modern desktop browser. Use a keyboard to play. Choose **Continue as Guest** to get started without an account.

Start with **Tutorial** to learn the flight controls. Use short bursts of thrust, watch your momentum, and slow down before landing.

## Controls

| Action | Key |
| --- | --- |
| Thrust | W or Up Arrow |
| Rotate left | A or Left Arrow |
| Rotate right | D or Right Arrow |
| Restart level | R |
| Advance after a campaign level | Enter |

In split screen, Player 1 uses **W, A, D** and **R**. Player 2 uses the **arrow keys** and **Enter** to restart.

Use **Backups** in the main menu to export your progress or restore a saved backup.
